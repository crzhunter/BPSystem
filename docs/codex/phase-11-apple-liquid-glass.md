# Phase 11 · 对局室初始化与 Liquid Glass 界面

2026-11-27 在 Windows、Node 24.15.0 与 Headless Edge 158.0.4370.33 上验收。生产构建、类型检查及 84 项测试通过。配置浮层采用 38px 折射倒角与柔焦中心，阵营和先选使用分段胶囊。

## 对局的三个生命周期

| 操作 | 盘面 | 阵容与偏好 |
| --- | --- | --- |
| 新开页面或普通刷新 | 第 1 手，0 Pick、0 Ban，使用 `7.42-standard`，与存档解除绑定 | 读取 `bp-setup-v4` |
| 首次读取本地战队 | 继续准备第 1 手 | 两边完全空白时，按战队 ID 顺序取前两队，各按首发位置 1–5 排列；跨队重复选手的位置留空 |
| 同一页面切换对局室、战队或录像等路由 | App 内存保留当前手数、撤销后的重做队列及绑定关系 | 保留 |
| 新开一局 | 清空动作和重做队列，解除旧存档绑定 | 保留两侧战队、首发、我方阵营、先选和直锁开关 |
| 打开存档浮层 | 只读取存档列表 | 保留 |
| 点击指定存档的「载入」 | 恢复该局的动作、顺序版本、修订号和文本 | 切换到该局阵容 |

`initialRoom(storage?)` 从旧到新逐字段读取 `bp-prep-v1`、`bp-live-v3`、`bp-setup-v4`，检查阵营、ID、五个槽位及重复选手。单个旧键的 JSON 损坏时仍可继续处理其余键。启动时移除两个旧键，`setupOf` 只投影以下七项。

```text
ourSide, firstPickSide, radiantTeamId, direTeamId,
radiantPlayerIds, direPlayerIds, instant
```

动作、会话 ID、修订号、标题和备注由内存盘面及用户主动保存的服务器存档承载。使用受限浏览器存储时仍可在内存开局。新环境默认开启单击直锁。通过配置浮层关闭后，刷新继续使用两步确认。

## 现场交互与存档一致性

- 状态胶囊集中显示版本、阵营、先选和队名。配置面板覆盖英雄池上部，外侧透明区域可关闭。面板内可以导入首发、逐位调整、同步战绩或对位，并展开查看首发战绩。
- 十个空 Pick 槽直接列出位置和昵称。点已锁英雄进入替换，Esc 取消。Pick 底部胶囊可以改位或绑人，已有选手和位置占用规则继续生效。
- 按 `/` 聚焦英雄搜索，按 `×` 清空。过滤保留 127 个格子的顺序和空间。英雄池、推荐卡、紧凑行与诊断芯片共用选人入口，成功锁定后清空搜索。
- 推荐请求进行期间保留最后一次成功结果。只有与当前盘面和优先位置匹配的建议才能参与自动绑定。切换盘面会取消过期的推荐请求。
- 绑定存档时，原位替换和位置分配先写入本机状态，再串行校验服务器修订号和动作前缀。已保存的手调用 `PUT /api/bp/sessions/:id/action/:stepIndex`，成功只合并修订号，因此请求期间新录入的手仍在。服务器版本冲突会提示保留本机改动，可重新载入或另存。
- 导航、角色和热图筛选共用可打断的分段弹簧，参数为 stiffness 460、damping 34、mass 0.75。浮层和路由处理退出动画，推荐排序使用位置布局动画。手机将推荐与诊断置于同一底部面板。

## 材质与折射

内容层保留冷曜石舞台、局部阵营环境光、四属性分组和英雄原画。交互层采用 Clear 胶囊与 Regular 浮层。Apple 文档提供内容与控件的分层原则；本项目的网页折射公式、色散系数和 SVG 实现采用本期工程要求。[Meet Liquid Glass](https://developer.apple.com/videos/play/wwdc2025/219/) · [Get to know the new design system](https://developer.apple.com/videos/play/wwdc2025/356/) · [Apple HIG Materials](https://developer.apple.com/design/human-interface-guidelines/materials)

1. `glassMath.ts` 以像素中心计算圆角矩形有符号距离及外法线。平坦区写入 RGBA(128,128,255,255)，外部写入 (128,128,0,255)。倒角带使用四次超椭圆截面，以折射率 1.5 求向内偏折，蓝通道记录截面高度。
2. `LiquidGlass.tsx` 将位移图按 4 CSS 像素量化并缓存，最多保留 80 项。观察器按动画帧合并尺寸变化，最终 SVG 滤镜范围仍使用控件的实际宽高。平坦矩形区批量写入，避免逐点计算法线。
3. Chromium 对实时背景做三路 RGB 位移。倒角的归一化偏折量取 0.42 次幂，使中段仍有可见曲率。高度场经 1.3px 平滑后生成镜面光，合成权重为 0.55。蓝通道的 255 专用于平顶，避免高度取整把斜面提前切平。
4. Regular 使用 32px 圆角、38px 名义倒角、86 位移尺度和 0.22 色散。倒角最多占短边一半减 2px。外环与 11px 柔焦中心之间使用 7px 羽化遮罩，以互补权重相加。表面叠加半透明渐变和上下内高光，文字在独立前景层绘制。Clear 使用 14px 名义倒角、38 位移尺度和 0.18 色散，保留清晰中心。
5. 玻璃高光固定为 135° 对角双弧。只有普通推荐卡响应指针，每个动画帧合并更新一次。配置打开时单独合成底层头像网格，按钮悬停即时反馈。非 Chromium 分支沿用 18px 背景模糊及高光环。
6. 桌面配置面板从英雄池左侧 32px、顶部 120px 处覆盖第一排头像。手机打开配置时将头像网格对齐到浮层下方，关闭时恢复进入位置。两侧首发保留战队导入、选手选择、录像入口和可展开的战绩。
